# oidc-starter-auth

Reusable Angular auth building blocks for the OIDC Starter sample.

This library is prepared for future npm packaging, but it is currently consumed from the local workspace only.

## Build

```bash
ng build oidc-starter-auth
```

## Public API

- `provideBffAuth`
- `BffAuthService`
- `BffCurrentUser`
- `provideSpaOidcAuth`
- `SpaAuthConfig`
