# Security Policy

Do not report suspected vulnerabilities through public GitHub Issues.

Please use [GitHub Private Vulnerability Reporting](https://github.com/MordaLabs/oidc-starter/security/advisories/new) for this repository instead. You can also report vulnerabilities to [security@mordalabs.com](mailto:security@mordalabs.com). Include a clear description, affected components or versions, reproduction steps or proof of concept when available, and any relevant impact details.
