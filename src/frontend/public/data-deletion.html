Facebook user data deletion

OIDC Starter is a public technical demo operated by Morda Labs. The hosted demo does not have a separate application database or dedicated user-profile store for Facebook profile information.

Session and token handling

The Facebook authentication handler does not save Facebook provider access or refresh tokens. Signing out ends the application's authenticated session, subject to normal browser and session-cookie behavior.

Facebook account data

Signing out does not delete information held independently by Facebook. Facebook controls data held in your Facebook account under Facebook's own policies.

Questions or concerns

If you have a question or believe information related to your demo interaction needs attention, email contact@mordalabs.com. To report a security issue, email security@mordalabs.com.
